# BFFLS-OSR-NEXT

> 北京市丰台区外国语学校开源项目 · 开源项目仓储
> **Beijing Fengtai Foreign Language School Open Source Repository (BFFLS-OSR-NEXT)**

开放共享 · 协同创新 · 学术交流 · 社会责任

本仓库以 **BFFLS-OSR-NEXT** 之名托管北京市丰台区外国语学校开源项目（**BFFLS-OSR**）的全部内容与站点。项目由学生发起、**OSR 管理委员会**托管维护，汇集校园师生在**教学科研、外语教育、科技创新、校园文化**等方面的原创内容——包括一条条由代码仙人、爬树仙人、红警仙人、鸡丁仙人、BW 等人物线延伸出的戏仿趣味页面，以及校长办学、抗战英烈纪念与法律声明。

访问在线站点：**https://rick-alstey.github.io**

---

## 版本 1.0（当前发布版）

### 概要
- **定位**：以工业科技沉浸风（黑灰白为主色，蓝/黄点缀，矩形元素）呈现的单页开源项目档案站。
- **内容**：汇总全部 **16 个分支**页面（角色人物线、戏仿学术、美食评鉴、游戏档案、怪谈、物理/数学建模、法律声明、英烈纪念、项目主页等），分 14 个主题分类，支持锚点卡片导航与全文阅读。
- **技术**：
  - 单文件自包含页面（HTML + CSS + JS），无额外依赖即可本地打开。
  - 引入 **KaTeX** 数学渲染，正确显示所有 LaTeX 公式（替换此前以反斜杠源码出现的乱码）。
  - 所有可点击入口使用**原生锚点**，跨环境稳定跳转。
  - 内置**图片占位/降级**处理，无外部图片阻塞加载。
- **资源**：已补齐并内嵌 **校徽**、**主席题字**（书法）、宫保鸡丁品质鉴评委员会**会徽**、以及游戏档案中的 **原神 / 艾尔登法环 / 使命召唤手游 / 战地风云 6** 等图片。
- **命名**：项目统一更名为 **BFFLS-OSR-NEXT**。
