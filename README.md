# BFFLS-OSR-NEXT

> 北京市丰台区外国语学校开源项目 · 开源项目仓储
> **Beijing Fengtai Foreign Language School Open Source Repository (BFFLS-OSR-NEXT)**

开放共享 · 协同创新 · 学术交流 · 社会责任

本仓库以 **BFFLS-OSR-NEXT** 之名托管北京市丰台区外国语学校开源项目（**BFFLS-OSR**）的全部内容与站点。项目由学生发起、**OSR 管理委员会**托管维护，汇集校园师生在**教学科研、外语教育、科技创新、校园文化**等方面的原创内容。

访问在线站点：**https://rick-alstey.github.io**

## 版本 1.2（当前发布版）

### 概要
本次更新聚焦**信息架构重构**：将原先 14 个细分主题分类，收敛为 **5 个板块**，导航更清晰、层次更分明。

| 板块 | 编号 | 收录内容 |
| --- | --- | --- |
| **介绍** | INTRO | 项目主页、免责声明、缅怀佟麟阁将军、《RUBBISH》论文归档 |
| **仙人系列** | XIANREN | 代码仙人（FW-Lang 丰外自研语法）、爬树仙人（刘忠毅校长）、红警仙人（红警怪谈） |
| **BW系列** | BW | BW 生物意志指数、BW 超高速状态统计力学、BW 超高速状态非经典力学 |
| **宫保鸡丁系列** | KPC | 宫保鸡丁品质鉴评委员会、游戏档案、花生摆放位置、评价方法、非守恒反应定理、鸡丁怪谈 |
| **其他 / 杂项** | MISC | 预留板块（当前暂无页面） |

- 顶部导航、页面索引与全文阅读区均按 5 板块重新组织。
- 空板块（其他/杂项）保留占位，便于后续内容归入。
- 全部 16 篇内容完整保留，公式渲染、图片与锚点导航不受影响。

## 版本 1.0

### 概要
- **定位**：以工业科技沉浸风（黑灰白为主色，蓝/黄点缀，矩形元素）呈现的单页开源项目档案站。
- **内容**：汇总全部 16 个分支页面，支持锚点卡片导航与全文阅读。
- **技术**：
  - 单文件自包含页面（HTML + CSS + JS），无额外依赖即可本地打开。
  - 引入 **KaTeX** 数学渲染，正确显示所有 LaTeX 公式（替换此前以反斜杠源码出现的乱码）。
  - 内置**图片占位/降级**处理，避免外部图片阻塞加载。
- **发布**：托管于 GitHub Pages，默认分支 `main`。
